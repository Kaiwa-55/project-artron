# คู่มือ Building Map Editor

## หน้าจอรุ่นล่าสุด: Map Builder

เปิดแท็บ **Map Builder** บนแถบหลักด้านบนของ Godot ใกล้ 2D/3D/Script หลังบันทึกงานแล้วเปิด Editor ใหม่เพื่อโหลดปลั๊กอินรุ่นนี้

ด้านซ้ายเป็นค่าตั้งแผนที่และปุ่มเลือกภาพ เลื่อนลงเพื่อดูตัวเลือกทั้งหมดได้ ด้านขวาเป็นพื้นที่วางบล็อก 3D พร้อมเมนูชั้น ชนิดบล็อก ช่องความกว้าง/ความลึกที่มีชื่อกำกับ และปุ่ม **Save map**

ภาพ สเกล ความสูง และ Snap จะอัปเดตอัตโนมัติ ใช้ **Top view** เพื่อวางตำแหน่งจากด้านบน, **3D view** เพื่อดูความสูง และ **Fit map** เพื่อกลับมาดูทั้งแผนที่ โหมด 2D เปิดได้ด้วย **Show optional 2D drawing**

Map Builder จะแสดงเฉพาะภาพของชั้นที่กำลังแก้เป็นค่าเริ่มต้น หากต้องการเทียบตำแหน่ง Level 1 กับ Ground ให้เปิด **Show lower floor** ชั่วคราว แล้วปิดเมื่อวางตำแหน่งเสร็จเพื่อไม่ให้ภาพสองชั้นซ้อนกัน

คำอธิบายตำแหน่งแถบ Building Map/Map 3D และปุ่ม Refresh ในส่วนด้านล่างเป็นตำแหน่งของรุ่นก่อน ให้ใช้หน้า Map Builder ตามคำแนะนำนี้แทน

Building Map Editor ใช้สร้างแผนที่หลายชั้นจากภาพ Dungeondraft โดยวาดพื้นที่เดิน กำแพง กำแพงล่องหน ช่องเปิด ราว และบันไดทับบนภาพ จากนั้นเครื่องมือจะสร้าง `BuildingMapData` และเพิ่มแผนที่เข้า Map Catalog ให้โดยอัตโนมัติ

### วาดกำแพงแบบเส้นและกำหนดความสูง

เลือกเครื่องมือ **Wall** แล้วลากจากจุดเริ่มถึงจุดปลายได้ทั้งในมุมมอง 3D และพื้นที่วาด 2D เส้นวางได้ทุกทิศทาง ก่อนวาดให้ตั้ง **Wall height ft** และ **Wall thickness px** ทางด้านซ้าย ค่าที่เลือกจะติดกับกำแพงเส้นนั้นโดยเฉพาะ

ในมุมมอง 3D ใช้ **Select** คลิกกำแพงเพื่อเลือก จากนั้นเปลี่ยนสองค่านี้เพื่อแก้กำแพงที่เลือกได้ ลากกำแพงที่เลือกเพื่อย้าย หรือกด Delete เพื่อลบ ความสูงที่บันทึกจะใช้ทั้งรูปร่าง 3D การชน และการบังสายตา แผนที่เก่าที่ใช้กำแพงสี่เหลี่ยมยังเปิดได้ และกำแพงเดิมที่ไม่เคยกำหนดความสูงจะใช้ 9 ft

## 1. เปิดเครื่องมือ

1. เปิด `project.godot` ด้วย Godot Editor
2. มองหาแท็บ **Building Map** ทางขวา
3. หากไม่พบแท็บ ให้เปิด **Project > Project Settings > Plugins**
4. เปลี่ยน **Building Map Editor** เป็น **Enabled**
5. หากแท็บยังไม่แสดง ให้ปิดและเปิด Godot Editor ใหม่

## 2. เตรียมภาพ

นำภาพ PNG เข้าโฟลเดอร์ภายในโปรเจกต์ก่อน เช่น:

```text
assets/maps/dungeondraft/my_map/Ground.png
assets/maps/dungeondraft/my_map/Level1.png
assets/maps/dungeondraft/my_map/Roof.png
```

ภาพทุกชั้นควรมีขนาดเท่ากันและใช้ตำแหน่งอ้างอิงเดียวกัน เพื่อให้กำแพง ช่องเปิด และบันไดตรงกันระหว่างชั้น

หลักการวางบันได:

- ภาพ Ground ใส่ภาพบันไดได้
- ภาพ Level 1 ไม่ต้องวาดภาพบันไดซ้ำ ให้เว้นพื้นที่ปลายบันไดเป็นช่องเปิด
- Godot จะสร้างทางลาดทรงลิ่ม 3D เชื่อมทั้งสองชั้น

## 3. ตั้งค่าพื้นฐาน

### Map ID

รหัสภายในของแผนที่ เช่น `wooden_watchtower` ใช้ตัวอักษรอังกฤษ ตัวเลข และขีดล่าง ไม่ควรซ้ำกับแผนที่เดิม

### Display name

ชื่อที่ใช้แสดง เช่น `Wooden Watchtower`

### Width และ Height

ขนาดพื้นที่พิกัดของแผนที่ ไม่จำเป็นต้องเท่ากับความละเอียดจริงของ PNG แต่สัดส่วนต้องตรงกับภาพ

ตัวอย่าง: ภาพ PNG ขนาด 2560 × 2560 สามารถกำหนดพื้นที่ทำงานเป็น 1600 × 1600 ได้ เพราะ UV ของภาพจะถูกย่อให้ตรงพื้นที่นี้

### Px/ft

จำนวนพิกเซลต่อหนึ่งฟุต ใช้แปลงพิกัดภาพเป็นระยะในโลก 3D

- ค่าเริ่มต้น: `12`
- ค่ามากทำให้สิ่งปลูกสร้างมีขนาดเล็กลงเมื่อคิดเป็นฟุต
- ค่าน้อยทำให้สิ่งปลูกสร้างมีขนาดใหญ่ขึ้น

ควรใช้ค่าเดียวกันกับแผนที่อื่นในเกมถ้าขนาดช่องกริดเท่ากัน

### Level ft

ความสูงของ Level 1 จาก Ground หน่วยเป็นฟุต ค่าเริ่มต้นคือ `10 ft`

### Snap pixels

ระยะล็อกกริดขณะวาด

- `1` วางได้ละเอียดระดับพิกเซล
- `5–10` เหมาะกับการเก็บรายละเอียด
- `20–50` เหมาะกับกำแพงหรือพื้นที่ขนาดใหญ่

จุดเริ่ม จุดจบ และขนาดของรูปทั้งหมดจะล็อกเข้ากริดนี้

## 4. เลือกภาพแต่ละชั้น

กด **Browse** แล้วเลือกไฟล์จากภายในโปรเจกต์:

- **Ground PNG** จำเป็นต้องมี
- **Level 1 PNG** จำเป็นเมื่อแผนที่มีชั้นสองหรือบันได
- **Roof PNG** ไม่บังคับ

เมนูเลือกชั้นด้านล่างใช้สลับภาพที่กำลังวาดระหว่าง **Ground** และ **Level 1**

## 5. เครื่องมือวาด

เลือกชนิดพื้นที่ แล้วลากเมาส์จากมุมหนึ่งไปยังอีกมุมหนึ่ง

### โหมดวางบล็อก 3D

เปิดแถบ **Map 3D** ด้านล่างของ Godot Editor แล้วกด **Refresh textures** หลังเลือกภาพหรือเปลี่ยนค่าขนาดแผนที่

- เลือก Ground หรือ Level 1 จากเมนูชั้น
- เลือก Floor, Wall, Invisible Wall, Opening, Railing หรือ Stairs
- กำหนดความกว้างและความลึกของบล็อกเป็นพิกเซล
- คลิกซ้ายเพื่อวางบล็อก โดยตำแหน่งจะใช้ค่า Snap pixels จากแถบ Building Map
- คลิกขวาใกล้บล็อกเพื่อลบ
- เลือก `Select` แล้วคลิกบล็อกเพื่อเลือก บล็อกจะเรืองแสงสีเหลือง
- ลากบล็อกที่เลือกเพื่อย้ายตำแหน่งตาม Snap pixels
- กด `Delete` หรือปุ่ม **Delete selected** เพื่อลบบล็อกที่เลือก
- กด `Esc` เพื่อยกเลิกการเลือก
- กดเมาส์กลางแล้วลากเพื่อเลื่อนกล้อง
- หมุนล้อเมาส์เพื่อซูม
- กด `Q` หรือ `E` เพื่อหมุนมุมกล้อง
- การวาง Stairs ใช้สองคลิก: จุดล่างก่อน แล้วจุดบน

บล็อกใน Map 3D และรูปทรงในโหมด 2D ใช้ข้อมูลชุดเดียวกัน เมื่อวางหรือลบบล็อกใน 3D ผลจะถูกนำไปบันทึกด้วยปุ่ม **SAVE + REGISTER MAP** ตามปกติ

### Walkable

พื้นที่ที่ตัวละครยืนและเดินได้

- Ground จะใช้ทั้งแผนที่เป็นพื้นที่เดินได้โดยอัตโนมัติ หากไม่ได้วาด Walkable เอง
- Level 1 ต้องวาด Walkable ให้ครอบคลุมพื้นชั้นบน
- แบ่งเป็นหลายสี่เหลี่ยมได้

### Wall

กำแพงทึบที่:

- ขวางการเดิน
- บังการมองเห็น 3D
- บังการยิงและการเลือกศัตรู
- สร้างเงาตามมุมกำแพง

อย่าวาด Wall ปิดทับช่องประตู ควรแบ่งกำแพงเป็นหลายช่วงแล้วเว้นช่องไว้

### Opening

ช่องเปิดของพื้น เช่น:

- ช่องบันได
- ช่องตก
- ช่องมองข้ามชั้น

Opening จะตัดพื้นที่ออกจากพื้นชั้นนั้น ตัวละครอาจมอง ยิง หรือถูกผลักผ่านช่องได้ตามกฎ 3D

### Invisible Wall

กำแพงล่องหนที่ขวางการเดิน แต่ไม่บังสายตา ไม่สร้างเงา และไม่ซ่อนศัตรู เหมาะสำหรับขอบฉาก พื้นที่ตกแต่ง หรือบริเวณที่ไม่ต้องการให้ตัวละครเดินเข้าไปโดยไม่มีผนังในภาพ

คุณสมบัติ:

- ผู้เล่นและ AI เดินผ่านไม่ได้
- ใช้เป็นสิ่งกีดขวางในการหาเส้นทาง
- มองเห็นตัวละครและศัตรูอีกฝั่งได้
- การยิงและการเลือกเป้าหมายผ่านได้
- ไม่สร้างเงาหรือพื้นที่มืด
- ไม่แสดงโมเดลกำแพงในเกม
- แสดงเป็นพื้นที่สีขาวโปร่งเฉพาะใน Building Map Editor

ตัวอย่างการใช้งาน:

- ปิดขอบแผนที่ที่ไม่มีผนังอยู่ในภาพ
- ป้องกันไม่ให้เดินเข้าไปบนของตกแต่งหรือพื้นที่นอกฉาก
- กั้นหน้าผาหรือพื้นที่อันตรายที่ยังไม่ต้องการใช้ระบบตก
- จำกัดทางเดินโดยไม่บดบังการต่อสู้ระยะไกล

อย่าใช้ Invisible Wall แทนกำแพงจริงเมื่อบริเวณนั้นควรบังสายตาหรือการยิง ให้ใช้ `Wall` ปกติแทน

### Railing

ราวระเบียงหรือสิ่งกีดขวางเตี้ย มี Collision 3D และใช้ในการตรวจแนวสายตา

วาดตามขอบระเบียง แต่เว้นจุดที่ต้องการให้เป็นทางเข้าออก

### Stairs

เลือก **Stairs** เพื่อวางบล็อกบันไดที่ปรับขนาดได้:

1. เลือก `Stairs` เครื่องมือจะสลับไป Ground
2. คลิกชานพักชั้นล่างหนึ่งครั้ง
3. เครื่องมือจะสลับไป Level 1 อัตโนมัติ
4. ปรับ `Block width px` เพื่อกำหนดความกว้าง และ `Block depth px` เพื่อกำหนดความยาวของบันได
5. คลิกตำแหน่งชานพักชั้นบนเพื่อกำหนดทิศทางของบล็อก ความยาวจะใช้ค่า Block depth
6. เครื่องมือจะสร้าง Opening บน Level 1 ครอบปลายบันไดให้อัตโนมัติ

ใช้ `Select` คลิกบล็อกบันไดสีม่วงแล้วลากเพื่อย้ายทั้งบันไดและ Opening ที่เชื่อมกัน หรือปรับ Width/Depth เพื่อย่อขยายบล็อกที่เลือก กด `Delete` เพื่อลบบันไดและ Opening ของมันพร้อมกัน

Godot จะสร้างบันไดเป็นลิ่มสามเหลี่ยม 3D พร้อมพื้นลาดและ Collision โดยอัตโนมัติ ตัวละครจึงหยุดกลางลาดได้

## 6. ลำดับการสร้างแผนที่ที่แนะนำ

1. กำหนด Map ID และชื่อ
2. ตั้ง Width, Height, Px/ft และ Level ft
3. เลือกภาพ Ground, Level 1 และ Roof
4. ตั้ง Snap เป็นค่าหยาบ เช่น `20`
5. วาด Walkable ของแต่ละชั้น
6. วาด Wall รอบอาคารและห้อง
7. ลด Snap เป็น `5` หรือ `10`
8. เก็บช่องประตูและมุมกำแพง
9. วาด Invisible Wall ตามขอบฉากหรือพื้นที่ที่มองผ่านได้แต่ห้ามเดิน
10. วาด Opening บน Level 1
11. วาด Stairs จาก Ground ไปยัง Opening
12. วาด Railing รอบช่องเปิดและระเบียง
13. กด **SAVE + REGISTER MAP**

## 7. Undo

ปุ่ม **Undo** จะลบรายการล่าสุดของเครื่องมือและชั้นที่เลือกอยู่

ตัวอย่าง: ถ้าเลือก Level 1 และ Wall ปุ่ม Undo จะลบ Wall ล่าสุดของ Level 1 เท่านั้น

## 8. การบันทึก

กด **SAVE + REGISTER MAP** เครื่องมือจะ:

1. ตรวจว่ามี Map ID และ Ground PNG
2. ตรวจว่ามี Level 1 PNG เมื่อมีบันได
3. ตรวจว่าปลายบันไดอยู่ใน Opening ของ Level 1
4. สร้างไฟล์ที่ `data/world/<map_id>/<map_id>_map.tres`
5. เพิ่มหรืออัปเดตแผนที่ใน `data/world/map_catalog.tres`

หากใช้ Map ID เดิม เครื่องมือจะอัปเดตรายการใน Catalog แทนการสร้าง ID ซ้ำ

## 9. นำแผนที่ไปใช้กับ Encounter

ใน Encounter Resource ให้กำหนด `building_map` เป็นไฟล์แผนที่ที่สร้างขึ้น เช่น:

```text
res://data/world/wooden_watchtower/wooden_watchtower_map.tres
```

ตั้ง `starting_surface_id` เป็น:

```text
ground
```

ตำแหน่งเกิดของผู้เล่นและศัตรูต้องอยู่ในพื้นที่ Walkable และไม่ซ้อนกับกำแพง ตัวละครอื่น หรือช่องเปิด

## 10. รายการที่ควรตรวจในเกม

- ตัวละครเกิดในตำแหน่งที่ถูกต้องและไม่ซ้อนกัน
- เดินผ่านประตูได้
- เดินทะลุกำแพงไม่ได้
- เดินทะลุ Invisible Wall ไม่ได้
- Invisible Wall ไม่บังเงา ศัตรู การยิง หรือการเลือกเป้าหมาย
- กำแพงบังเงา ศัตรู และการเลือกเป้าหมายตรงกัน
- เดินขึ้นและลงบันไดได้โดยไม่ต้องกดปุ่มพิเศษ
- หยุดกลางทางลาดและเดินต่อได้
- มองหรือยิงข้ามชั้นได้เมื่อมีช่องเปิด
- ระเบียงและราวอยู่ตรงกับภาพ
- ช่องเปิดรองรับการตกหรือการผลักจากที่สูง

## 11. ข้อจำกัดของรุ่นปัจจุบัน

- รูปทรงที่วาดเป็นสี่เหลี่ยมผืนผ้า
- รองรับ Ground และ Level 1 ในหน้าวาด ส่วน Roof เป็นชั้นภาพประกอบ
- บันไดที่สร้างจากเครื่องมือเชื่อม Ground ไป Level 1
- ยังโหลดแผนที่เดิมกลับมาแก้ในหน้าวาดไม่ได้
